## 二、主线与热点

**判断一个方向是否主线，看四点：**

| 维度 | 判断标准 |
|------|---------|
| 政策/消息驱动 | 实质性政策/产业催化 → 强；纯传闻/小作文 → 弱 |
| 板块涨停数量 | 5+ 涨停才算"主线级别" |
| 龙头高度 | 有 3 板以上龙头 → 赚钱效应示范强 |
| 资金容量 | 板块内 500 亿以上大票同步上涨 → 机构认可、持续性更强 |

**持续性验证（Day1→Day4）：**
- Day1 启动涨停潮 → 标记候选；Day2 龙头连板+中军不跌+助攻 → 确认；Day3 分歧（炸板但回封）→ 正常；Day4 分歧转一致再爆发 → 确立。
- 反之 Day2 大面积退潮、龙头闷杀 → 一日游，放弃。

**实操参考：** 新题材看第一天，确认看第二天，分歧买第三天，高潮卖第四天。

**记录：** 最强板块 + 逻辑；强度排序；持续性判断（启动/回流/一日游）；涨停梯队结构；资金风格（机构/游资/量化）。

## 三、涨停数据（封板率）

```
封板率 = 封住涨停数 ÷ (封住涨停 + 炸板数)
打开率 = 1 - 封板率
```
> 封板率 >75% 情绪高涨；60-75% 正常精选；<50% 恐慌，谨慎。

**记录：** 涨停家数 / 封板率 / 打开率 / 连板高度；昨日涨停今日溢价（高开/低开比例）；炸板股及其分歧方向。

## 四、资金面

| 指标 | 怎么看 |
|------|--------|
| 两市融资余额 | 连续增加=增量进场；连续减少=资金撤离 |
| 融资净买入额 | 单日大额净买入 → 情绪偏多 |
| 融券余额 | 大增 → 做空力量增强，注意回调 |

**记录：** 两融余额变化；融资净买入靠前板块/个股；信号定性（进场/撤退/观望）。

## 五、龙虎榜

| 看什么 | 怎么用 |
|--------|--------|
| 知名游资席位 | 他们买的方向常是当前主线 |
| 机构专用席位 | 净买=趋势票逻辑硬；净卖=获利了结 |
| 买卖力量对比 | 净买入金额大且为正 → 强势 |
| 一线游资是否锁仓 | 昨日买榜今日还在 → 格局；不在 → 一日游 |
| 量化席位 | 大量出现 → 波动大、持续性差 |

**记录：** 净买入前3标的 + 买方构成；有无"机构+游资"共振；昨日买榜今日是否卖出。
