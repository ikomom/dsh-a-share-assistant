# 📊 每日复盘模板

> 炒股赚的是认知的钱。每天比昨天多懂一点，每天对账单、纠偏差。

---

## 一、大盘环境

> 判断当下是赚钱效应期还是亏钱效应期，决定仓位上限。

| 维度 | 记录项 |
|------|--------|
| 指数 | 上证 / 深证 / 创业板 涨跌幅 |
| 量能 | 两市成交额，较昨日放量/缩量多少 |
| 涨跌家数 | 普涨 / 普跌 / 分化 |
| 北向资金 | 净流入/流出（如有关注） |
| 涨停/跌停数 | 涨停家数、连板高度、跌停家数 |
| 市场情绪定性 | 🟢进攻 / 🟡震荡 / 🔴退潮 |

**一句话总结：** 今天市场整体氛围如何，钱在流入还是流出。

---

## 二、主线与热点追踪

> 找到当前最强的方向，判断持续性。核心方法：**四维度评分 + 持续性验证**。

### 第一步：找到今日涨幅前10的板块

圈出前5-10个候选板块。

### 第二步：四维度评分（每项1-5分）

| 维度 | 判断标准 |
|------|---------|
| **① 政策/消息驱动** | 实质性政策/产业催化 → 5分；纯小作文/传闻 → 2分 |
| **② 板块涨停数量** | 5+涨停才算"主线级别" |
| **③ 龙头高度** | 有无3板以上龙头 → 有则赚钱效应示范强 |
| **④ 资金容量** | 板块内有无500亿以上大票同步上涨 → 有=机构认可=持续性更强 |

**总分 ≥ 15分 → 主线，重点跟踪**
**10-14分 → 支线，可参与但不重仓**
**< 10分 → 一日游概率大，只看不做**

### 第三步：持续性验证（Day1 → Day4）

```
Day1: 板块启动，涨停潮 → 标记为"候选主线"
Day2: 龙头继续连板 + 中军大票不跌 + 新首板助攻 → ✅ 确认主线
Day3: 分歧日（龙头炸板但回封，板块小幅调整）→ 正常分歧，主线生命力还在
Day4: 分歧转一致，再次爆发 → 主线确立，可能走2-3周
```

**反之：** Day2 就大面积退潮、龙头闷杀 → 一日游，放弃。

### 第四步：实操口诀

> **"新题材看第一天，确认看第二天，分歧买第三天，高潮卖第四天"**

- 新题材启动（Day1）：先观察，不急着追
- 确认（Day2）：龙头确立，可以试仓
- 分歧（Day3）：龙头分歧换手，是**最佳买点**
- 高潮（Day4）：板块全面爆发涨停潮 → **该卖了**，不是该买

### 本日记录区

- **今日最强板块：** （板块名 + 驱动逻辑）
- **板块强度排序：** 1→5 名
- **是否有持续性：** 新题材启动 / 老题材回流 / 一日游
- **涨停梯队：** 最高板 → 中位 → 首板结构是否健康
- **资金风格：** 机构（趋势大票）/ 游资（连板小票）/ 量化
- **四维度评分：** ① __ ② __ ③ __ ④ __ = 总分 __

**关键思考：** 如果明天要出手，我只能买一个方向，是哪个？为什么？

## 三、涨停数据（封板率 / 打开率）

> 反映市场情绪的"温度表"——封板率高说明打板资金敢干活，赚钱效应好。

**计算公式：**
```
封板率 = 封住涨停的个股数 ÷ (封住涨停 + 盘中炸板数)
打开率 = 1 - 封板率
```

**实战判断标准：**

| 封板率 | 市场状态 |
|--------|---------|
| > 75% | 情绪高涨，打板胜率高 |
| 60%-75% | 正常，精选标的 |
| < 50% | 恐慌，打板容易被埋，空仓观望 |

**记录区：**
- 今日封板率：__%
- 打开率：__%
- 昨日涨停今日溢价率：高开 / 低开比例
- 炸板股有哪些 → 资金在哪个方向分歧最大

## 四、龙虎榜

> 看"谁在买"——顶级游资、机构、北向的动向就是风向标。

| 看什么 | 怎么用 |
|------|--------|
| **知名游资席位** | 赵老哥、方新侠、呼家楼、作手新一等 → 他们买的方向就是当前主线 |
| **机构专用席位** | 机构净买入=趋势票逻辑硬；机构净卖出=获利了结 |
| **买卖力量对比** | 买方总金额 vs 卖方总金额 → 净买入为正且金额大=强势 |
| **一线游资是否锁仓** | 昨天买榜的游资今天还在不在 → 在=格局，不在=一日游 |
| **拉萨天团（量化）** | 拉萨席位大量出现 → 量化主导，波动大、持续性差 |

**记录区：**
- 今日龙虎榜净买入前3标的 + 买方席位构成
- 有无"机构+游资"共振的票？（机构游资同买 = 最强信号之一）
- 昨日买榜游资今日是否卖出（判断持续性）

## 五、今日操作回顾

| 标的 | 买入逻辑 | 卖出/持有 | 盈亏 | 符合预期？ |
|------|---------|-----------|------|-----------|
|      |         |           |      | ✅/❌ |

**对每笔交易追问三个问题：**
1. **买点：** 我为什么今天买？是计划内的还是冲动追的？
2. **卖点：** 卖出依据是纪律止损/止盈，还是情绪恐慌/贪婪？
3. **仓位：** 这个仓位大小是否匹配我的胜率和赔率判断？

## 六、交易心理复盘

> 最容易被忽视但最致命的部分。

- **今日情绪状态：** 平静 / 焦虑 / 兴奋 / 犹豫
- **有没有违反纪律：** 追高、扛单、频繁操作、重仓单吊？
- **FOMO（害怕错过）出现了吗？** 具体哪个时刻？
- **最大的情绪干扰是什么？**

## 八、明日计划

| 情景 | 触发条件 | 应对策略 |
|------|---------|---------|
| 看多（大概率） | 什么条件成立 | 出手方向 + 仓位 |
| 看空（防御） | 什么条件触发 | 减仓/空仓 |
| 关键观察标的 | —— | 列入自选重点跟踪 |

**铁律三条：**
- 单票仓位不超过总资金 ___%
- 单日最大亏损不超过 ___%（止损线）
- 盘前写计划，盘中只看信号执行，盘后回来对账

---

## 💡 使用建议

1. **复盘不在长，在"对账"**——每天对照昨日计划看执行偏差，比写三千字心得有用
2. **区分"事实"和"观点"**——"今天AI大涨"是事实，"明天AI还会涨"是观点，分开写
3. **重点记录亏损**——盈利可能是运气，亏损一定是学费，把每一笔亏损归因到具体原因
4. **每周做一次周汇总**——看一周内重复犯的错误模式

## 🔗 整套体系的核心逻辑

> **封板率 + 龙虎榜** → 看情绪和资金在不在
> **融资融券** → 看大资金方向
> **主线四维度** → 看哪个方向值得下注
> **操作复盘** → 看自己有没有执行到位
